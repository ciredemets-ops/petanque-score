# Pétanque Score

Application autonome de score pour la pétanque, installable sur smartphone, fonctionnant en portrait, paysage et hors ligne.

## V0.1

- Tête-à-tête / Doublette / Triplette
- Noms libres
- Boutons +1 à +6
- Mène nulle
- Annuler
- Enregistrer
- Réinitialiser
- Historique des mènes
- Chronomètre
- Fin automatique à 13
- Revanche / Nouvelle partie
- Sauvegarde locale
- Fonctionnement hors ligne via Service Worker
- PWA installable
